## 🎯 Overview

This repository documents my structured learning journey and technical coursework in **C# and .NET full-stack development**. It covers language fundamentals, memory and resource management, object-oriented design principles, interfaces, pattern matching, and problem-solving assignments.

---

## 📚 Curriculum & Topic Breakdown

### 🔹 Module 1: C# Language Fundamentals (`Day-2`)
- **Type System:** Primitive data types, reference types, type safety, and `var` implicit typing.
- **Null Safety:** Nullable value types, null-coalescing operators, and defensive coding.
- **Control Flow:** Conditionals, logical operations, iterative loops, and modern pattern matching (`switch` expressions).
- **Collections & Namespaces:** Working with arrays, generic lists, and namespace organization.

### 🔹 Module 2: Object-Oriented Programming & Interfaces (`Day-3`, `Day-4`)
- **Classes & Objects:** Fields, auto-implemented properties, constructors, and encapsulation.
- **Inheritance:** Base class constructors, method overriding, and the `base` keyword.
- **Interfaces & Polymorphism:** Implementing single and multiple interfaces (`IMusicPlayer`, `MultipleInterfaceDemo`).
- **Static Members:** Static utility classes and singleton-style methods.

### 🔹 Module 3: Resource Management & Advanced C# (`Day-6`, `Day-24`)
- **Deterministic Cleanup:** Implementing the `IDisposable` pattern and `using` statements for unmanaged resources.
- **Modern Syntax:** Expression-bodied members and lambda expressions.
- **Algorithms & Problem Solving:** Palindrome verification, custom logger implementations, and array search utilities.

## 🚀 How to Run the Solutions

### Prerequisites
- [.NET SDK 8.0+](https://dotnet.microsoft.com/download)
- Visual Studio 2022 or VS Code with C# Dev Kit extension

### Execution via .NET CLI
```bash
# Clone the repository
git clone https://github.com/Sahil860534/dotnet.git
cd dotnet

# Run any daily module project
cd "Day-2"
dotnet run
```
